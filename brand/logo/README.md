# Logo kit: Apuração Cidadã

Approved 2026-10-14 by Alino (direction **A, "QR conferido"**). This is the source of truth for the logo.
**Placed 2026-10-14** in the PWA, the Expo app and the repo README (see **Where each file goes**).
Agents: when the kit changes, re-copy following **Where each file goes** below. Do not redraw, recolour or
re-typeset the logo anywhere; copy files from here.

## The idea
A minimal QR Code: three finder corners, and the fourth corner is the check of the citizen who confirmed it.
It comes from the app's core gesture (scan the QR of the ballot report on the section door) and says "conferido".

## Colours
| Token | HEX | RGB | Use |
|---|---|---|---|
| Verde-mata | `#0F5257` | 15 82 87 | QR corners, "Apuração", icon tile, dark background. App `primary`. |
| Turquesa-selo | `#1F8F83` | 31 143 131 | Check + "Cidadã" **on light backgrounds** (3.9:1 on white) |
| Turquesa | `#3BB3A6` | 59 179 166 | Check + "Cidadã" **on dark / verde-mata** (3.5:1). App `secondary`. |
| Superfície | `#F2F7F6` | 242 247 246 | Preferred light background |
| Âmbar | `#F4A261` | — | App accent only (scan button). **Never in the logo.** |

Why: deep green = trust and security, turquoise = the act of checking. No red (PT), no green-yellow or blue (PL),
nothing that imitates the TSE identity (CLAUDE.md non-negotiables).

## Where each file goes
**PWA (`app/`)**
- Copy `web/favicon.svg`, `web/favicon.ico`, `web/apple-touch-icon.png`, `web/icon-192.png`, `web/icon-512.png`,
  `web/maskable-512.png`, `web/og-image.png` into `app/public/`.
- `app/index.html` `<head>`:
  ```html
  <link rel="icon" href="favicon.ico" sizes="48x48">
  <link rel="icon" href="favicon.svg" type="image/svg+xml">
  <link rel="apple-touch-icon" href="apple-touch-icon.png">
  <meta property="og:image" content="og-image.png">
  ```
  (`theme-color` stays `#0F5257`; use an absolute URL for `og:image` once the domain exists.)
- `app/public/manifest.webmanifest` `icons`: `icon-192.png` (192x192), `icon-512.png` (512x512),
  `maskable-512.png` (512x512, `"purpose": "maskable"`); `background_color` `#0F5257`.
- In-app: copy `svg/symbol-reverse.svg` → `app/public/logo-mark.svg` (top bars), `svg/horizontal-reverse.svg` →
  `app/public/logo.svg` (welcome), `svg/horizontal.svg` → `app/public/logo-light.svg` (About).
- Bump `CACHE` in `app/public/sw.js` so installed PWAs drop the old cached icons/manifest.

**Mobile (`mobile/`, private repo)**
- Copy `mobile/icon.png` → `mobile/assets/icon.png`, `android-icon-foreground.png` and
  `android-icon-monochrome.png` → `mobile/assets/`, set `android.adaptiveIcon.backgroundColor` `#0F5257`.
- Splash: `splash-icon-reverse.png` with splash `backgroundColor` `#0F5257` (or `splash-icon.png` on `#F2F7F6`),
  (the mark is 40% of the 1024 image, so `resizeMode: contain` shows it at a sensible size).
- In-app logo: `mobile/src/logoSvg.ts` holds the SVG strings (`MARK_REVERSE`, `MARK`, `LOCKUP_REVERSE`, `LOCKUP`) rendered
  with `SvgXml`; `Screen` shows the mark on top-level screens, `<Logo>` (src/ui.tsx) on welcome and About.
  Regenerate after rebuilding the kit:
  ```bash
  python3 -c "import re,json;f=lambda n:re.sub(r'<title>.*?</title>','',open(f'brand/logo/svg/{n}.svg').read()).strip();open('mobile/src/logoSvg.ts','w').write('// Generated from brand/logo/svg (public repo). Do not edit: rebuild the kit, then rerun the copy in brand/logo/README.md.\n'+''.join(f'export const {k} = {json.dumps(f(n))}\n' for k,n in [('MARK_REVERSE','symbol-reverse'),('MARK','symbol'),('LOCKUP_REVERSE','horizontal-reverse'),('LOCKUP','horizontal')]))"
  ```

**Repo README**: `svg/horizontal.svg` with `svg/horizontal-white.svg` for GitHub dark mode.
**GitHub social preview**: upload `web/og-image.png` in repo Settings → Social preview (manual, no API).
**Elsewhere**: social avatar = `web/icon-512.png`; videos/reels = `png/horizontal-reverse.png` or `png/symbol-reverse.png`.

## Usage rules
- **Clear space:** at least one QR corner's ring+gap (= 32/256 of the symbol height) on every side.
- **Minimum size:** symbol 24 px (use `symbol-small` from 32 px down; 16 px favicon is `symbol-small`);
  horizontal lockup 120 px wide; inline 160 px wide.
- **Backgrounds:** colour version on white/`#F2F7F6`; reverse on `#0F5257` or `#0D2224`; on photos use white one-colour.
- **Don't:** recolour (especially red, yellow, blue, party colours); put the check in amber; rotate, stretch or add
  shadows/gradients; change the order of the corners or move the check; retype the name in another font; use the
  colour version on verde-mata (low contrast); put the logo next to TSE marks as if official.
- Both candidates are never coloured with brand colours; the logo stays neutral in every context.
